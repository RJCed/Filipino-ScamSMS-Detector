# Filipino SMS Scam Detector

A machine learning cybersecurity project that aims to detect scam messages in Filipino SMS.

**Status:** Under development — the dataset still needs further cleaning, validation, and refinement.

## Datasets

This project uses the following datasets:

- [Tagalog SMS Dataset](https://www.kaggle.com/datasets/onzero0/tagalog-sms/data) by [onzero0](https://www.kaggle.com/onzero0)
- [Philippine Spam SMS Messages](https://www.kaggle.com/datasets/bwandowando/philippine-spam-sms-messages) by [bwandowando](https://www.kaggle.com/bwandowando)
- [Filipino Gossip Dataset](https://huggingface.co/datasets/jhenberthf/filipino-gossip-dataset) by [jhenberthf](https://huggingface.co/jhenberthf)
